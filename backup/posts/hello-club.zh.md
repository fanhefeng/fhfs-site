《爱乐之城》的结尾，Mia 推门走进那家爵士俱乐部，墙上挂着她多年前替 Sebastian 画的招牌——**Seb's**，霓虹灯管一亮，整个故事都亮了。

我想要的个人网站，就是那种感觉：

- 夜色是深蓝的，不是纯黑；
- 灯是暖的，字是发光的；
- 音乐不吵，但一直在。

## 这里会有什么

我会在这里写随笔、放作品、列出我做过的软件。就当这是我的小酒馆，你随时可以推门进来坐坐。

```ts
const club = {
  name: "Seb's",
  openAt: "midnight",
  music: "jazz",
};
```

欢迎光临。
