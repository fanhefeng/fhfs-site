### 构建隔离与依赖

使用独立类型配置；正常 `.next` 的 BUILD_ID 和预渲染清单在完整测试前后未改变。

## 环境问题与审查边界

本机媒体域名 DNS 返回 `198.19.0.80` 等非公网代理地址，Next 图片优化器因此返回 400。
同一媒体图片经线上站点优化返回 200 / image/jpeg。应在代理 fake-IP 过滤中排除媒体域名，
再重新验收说说页；不能开启 `dangerouslyAllowLocalIP` 绕过 SSRF 保护。
最初的默认客户端媒体请求返回 403；使用普通浏览器 User-Agent 复测一条音频，HEAD 返回
200，首段和尾段均返回正确的 206、1024 字节及 Content-Range，越界返回正确的 416。
这只证明该样本的请求响应，全部媒体与真实 Safari/iOS 播放仍需进一步检查。

CodeRabbit 完成两轮包含新增文件的差异审查：后台默认年份的站点时区、旧构建目录文档，
以及文章测试清理条件过宽均已修正；没有重大或警告级发现。清理现在只匹配测试生成的前缀及
两个固定样本，专用测试库的准备命令再次通过。运行验证还修复了 macOS 中断清理的进程组竞态
和 restic 分组 JSON 导致健康检查误报，分别通过真实中断和先失败后通过的自测验证。
外部审查与首次异地备份、真实数据库恢复和恢复库站点验收分别完成，不互相替代。
凭据模式扫描未发现真实令牌或私钥；`.env.local`、测试会话和媒体目录均被忽略。

Next 的 Cache Components 迁移目前是明确推迟的架构选择，不是本次构建失败原因。
若未来迁移，应整体处理读取层并核对所有公开路由仍可预渲染；不要逐个 getter 混改。
