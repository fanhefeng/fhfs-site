作者已确认私人家书和日记留在 Obsidian。未导入带日期的私人记录、家书、亲人纪念日记，以及只有网页截图的作文资料。来源不明的句子合集继续留在本地。没有上传照片、截图或任何私人附件。

选编只做以下明确调整，不重写作者的语气：

- 社区食堂保留第一版完整原文，去掉分隔线之后的改稿建议和未完成重写。
- 「我说的」按原顺序选录五则：离开北京、包子、困惑、公车随感、蓝天。其余私人段落留在本地。
- Web3 选录课程与技术部分，不发布原笔记中的交易所、钱包排行榜及合规断言。
- 装饰器原稿主要摘自网道教程，改为署名的原文资料入口。乔布斯演讲、比特币白皮书同样保留原作者与原文入口；马徐骏文章未找到原笔记记录的可核实网址，仅保留书目。

- YAML frontmatter 不显示在正文；Obsidian 提示块作为普通引用呈现。代码高亮支持明暗主题，宽表格在正文内横向滚动。

## 展示方式

手记采用有编号分区的目录，显示标题、摘要、类型、语言、标签和阅读时间；有明确记录的日期才显示日期。分类状态保存在 URL，关键词可以组合查询。不同类型共享阅读页，不为短记添加虚构封面或日期。长技术笔记提供可折叠目录，章节链接有固定导航避让。

## 更新

`scripts/notebook/catalog.ts` 是明确的公开白名单，包含源文件相对路径、标题、摘要、分区和选编规则。导入器**不遍历整个笔记库**，不修改 Obsidian，不读取 `.env`，不连接或写入数据库。

```sh
pnpm import:notebook /Users/fhf/Documents/Obsidian/note
pnpm exec vp fmt src/content/notebook
pnpm check
pnpm build
pnpm preview --port 4181
# 另一个终端
pnpm smoke http://127.0.0.1:4181
node scripts/smoke-notebook.mjs http://127.0.0.1:4181
```

生成的 `src/content/notebook/index.json` 只含列表元数据，`pages/*.json` 分篇存放经过现有安全 Markdown 管线渲染的正文。服务端按需加载正文，列表不携带全部文章。生成结果随本部署版本更新，原始私人笔记不会成为运行时依赖；后台继续管理原有数据库内容，不会覆盖这些文件。

新增公开条目先审阅源文件、日期和归属，再加入白名单。选择段落使用明确的开头定位，原稿变化导致定位失败时会停止；缺少文件、潜在凭据、未解析的 Obsidian 附件会中止导入。全部条目准备完成后才写入内容集，移出白名单的正文文件在下次导入时清理。

这些规则用于内容整理，不意味着已经对所有历史学习笔记做过技术校订。
