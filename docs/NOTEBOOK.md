# Obsidian 导入内容

导入的 20 条公开内容按主题归入现有「文章」与「生活」，没有独立的手记版块。技术内容在 `/blog`，生活内容直接列在 `/life`，阅读页沿用现有随笔地址 `/secrets/:slug`。站内搜索、标签、相邻篇目与 sitemap 使用归类后的地址；生活页不新增导航栏目。正文未翻译时保留原语言标记、回退提示和原语言 canonical；不伪造翻译或写作日期。

## 内容判断

本次只分析 `笔记`、`写作`、`IT`：共 31 个 Markdown 文件，选取 20 条公开内容。求职、存储、Personal、模板与工具目录不属于此次导入范围。

| 来源与归属 | 数量 | 处理方式 |
| --- | ---: | --- |
| 写作 → 生活 `/life` | 4 | 独处、社区食堂、职业生涯、从头再来。长文阅读；学生时代文章注明旧文，不补造年份。 |
| 生活笔记 → 生活 `/life` | 5 | 食谱、五则随想、点子，以及乔布斯演讲和马徐骏文章的阅读资料卡。 |

作者已确认私人家书和日记留在 Obsidian。未导入带日期的私人记录、家书、亲人纪念日记，以及只有网页截图的作文资料。来源不明的句子合集继续留在本地。没有上传照片、截图或任何私人附件。

选编只做以下明确调整，不重写作者的语气：

- 社区食堂保留第一版完整原文，去掉分隔线之后的改稿建议和未完成重写。
- 「我说的」按原顺序选录五则：离开北京、包子、困惑、公车随感、蓝天。其余私人段落留在本地。
- Web3 选录课程与技术部分，不发布原笔记中的交易所、钱包排行榜及合规断言。
- 装饰器原稿主要摘自网道教程，改为署名的原文资料入口。乔布斯演讲、比特币白皮书同样保留原作者与原文入口；马徐骏文章未找到原笔记记录的可核实网址，仅保留书目。
- ethers 原稿混用不同版本 API，页面注明版本情况；表单内存笔记缺少复现条件，改标为「观察记录」，保留原文而不将其作为已验证结论。
- YAML frontmatter 不显示在正文；Obsidian 提示块作为普通引用呈现。代码高亮支持明暗主题，宽表格在正文内横向滚动。

## 展示方式

技术内容融入现有文章列表；生活内容直接列在生活页已有房间目录之后，使用同样的按年份文字目录，阅读后返回生活页。有记录的日期按时间排序；没有日期的原稿排在「日期未记」下，不归入虚构年份。阅读页保留类型、阅读时间、选编说明、原作者与出处，长技术笔记保留可折叠目录。RSS 仅收录有记录日期的文章。

旧 `/blog/notes` 永久跳转到 `/blog`；带 `section=writing` 或 `section=life` 的旧目录跳转到 `/life`。旧 `/blog/notes/:slug` 按内容永久跳转到 `/blog/:slug` 或 `/secrets/:slug`，保留访问语言前缀。旧入口不再出现在页面、搜索或 sitemap 中。

## 更新

`scripts/notebook/catalog.ts` 是明确的公开白名单，包含源文件相对路径、标题、摘要、来源分类和选编规则。导入器**不遍历整个笔记库**，不修改 Obsidian，不读取 `.env`，不连接或写入数据库。

```sh
pnpm import:notebook /Users/fhf/Documents/Obsidian/note
pnpm exec vp fmt src/content/notebook
pnpm check
pnpm build
pnpm start --port 4181
# 另一个终端
pnpm smoke http://127.0.0.1:4181
node scripts/smoke-notebook.mjs http://127.0.0.1:4181
```

生成的 `src/content/notebook/index.json` 只含列表元数据，`pages/*.json` 分篇存放经过现有安全 Markdown 管线渲染的正文。服务端按需加载正文，列表不携带全部文章。生成结果随本部署版本更新，原始私人笔记不会成为运行时依赖；后台继续管理原有数据库内容，不会覆盖这些文件。公开读层合并导入内容；同目标版块出现同名 slug 时，以数据库内容及其真实语言版本为准，避免重复。数据库拥有权覆盖草稿和所有语言版本：同名记录全部设为草稿后，公开详情、列表、标签、搜索和 sitemap 均隐藏该地址，不回退到导入原稿；仍可在鉴权预览中读取草稿。数据库 schema、公开缓存期限和管理员预览规则保持兼容。

新增公开条目先审阅源文件、日期和归属，再加入白名单。选择段落使用明确的开头定位，原稿变化导致定位失败时会停止；缺少文件、潜在凭据、未解析的 Obsidian 附件会中止导入。全部条目准备完成后才写入内容集，移出白名单的正文文件在下次导入时清理。

这些规则用于内容整理，不意味着已经对所有历史学习笔记做过技术校订。
